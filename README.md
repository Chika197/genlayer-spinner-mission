# GenLayer SpinnerMission

A simple interactive GenLayer transaction status spinner that visualizes the consensus lifecycle from pending to finalized.

## Overview

GenLayer SpinnerMission demonstrates the lifecycle of a GenLayer transaction through a simple interactive UI.

The spinner visualizes these stages:

1. Pending
2. Proposing
3. Committing
4. Revealing
5. Accepted
6. Finalized

Users can simulate the consensus process and observe the status transition until finalization.

## Features

- Interactive GenLayer transaction status spinner
- Visual consensus lifecycle
- Simulated transaction progression
- Finalized state indicator
- Simple and lightweight frontend
- Deployed using GitHub Pages
